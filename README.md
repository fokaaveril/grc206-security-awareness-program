# grc206-security-awareness-program
12-month security awareness program for a fictional logistics company: risk assessment, role-based training, phishing simulation, behaviour metrics and a program calendar.
This is my submission for GRC206 (Designing a Successful Security Awareness Program) at the International Cybersecurity and Digital Forensics Academy (ICDFA). It designs a 12-month awareness program for Northbridge Logistics, a fictional company with 800 staff across head office, warehouses and remote sales, using the five-stage lifecycle: assess, plan, deliver, measure, improve.

What it covers

Assess: the top three human-driven risks (invoice fraud and phishing, password reuse, and mishandling regulated data), five audiences and a pre-launch baseline.
Plan: three measurable objectives, sponsor and owners by role, and topics for each audience.
Deliver: formats for warehouse and office roles, onboarding, a supportive phishing simulation approach and a no-blame reporting route.
Measure: six metrics covering reach, behaviour and outcomes, with leadership reporting.
Improve: a quarterly review routine, learner feedback, recognition and a one-page 12-month calendar.
